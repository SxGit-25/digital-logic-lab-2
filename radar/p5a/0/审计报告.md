## 2. 接口、空读与总线换向

LCM12864-14 手册 PDF 第3页明确指定 ST7565R、Intel 8080 时序和8位并口，并注明可通过PCB跳线改为6800；已渲染核对该页。实验板手册 PDF 第13页列出 LCD_RD、LCD_WR、A0、RST、CS、D7..D0 的 EPM1270 引脚，与 QSF 完全匹配。RTL 使用独立低有效 RD/WR，是8080实现。实物跳线仍须由用户确认，文档无法远程证明其当前位置。

每个像素由 `radar_lcd_micro` 的 RMW 状态完成8笔事务：

```text
0 写页 -> 1 写列高 -> 2 写列低 -> 3 空读 -> 4 真读
-> 5 重新写列高 -> 6 重新写列低 -> 7 写回 old & ~mask 或 old | mask
```

事务3读回值被事务4覆盖，事务7使用后者。每次准备读取新地址都先空读一次。事务5/6只用于写回前恢复列位置，后面没有读事务，因此不需要追加空读。当前不是使用 ST7565 的0xE0硬件 RMW 命令。

数据总线由顶层 `assign lcd_data=oe ? data_out : 8'bz` 控制。ENABLE_READBACK=1时空闲/读均高阻，只有写周期驱动。`lcd_bus_phase` 先释放 OE，再等待20clk才选通CS，再等待4clk拉低RD；RD下降后9clk采样，10clk拉高RD，随后6clk恢复。由RD上升到下一写驱动至少有6clk恢复及握手间隔，覆盖行为模型50ns释放时间。模型同时检查读写所有权、争用、地址流水线和脉宽。

| 项目 | 标称实现 | 相对手册 / 工程检查余量 |
|---|---:|---|
| 写建立 | 80 ns | 手册40 ns；模型52 ns，余28 ns |
| WR低 | 120 ns | 手册80 ns；模型104 ns，余16 ns |
| RD低 | 200 ns | 手册140 ns；模型182 ns，余18 ns |
| 总线恢复 | 120 ns | 模型高电平104 ns，余16 ns |
| 写周期主体 | 320 ns | 手册240ns×1.3=312ns，余8ns，另有握手间隔 |
| 读前高阻 | 至少400 ns，实际至RD下降480 ns | 模型要求至少400 ns |
| RD下降到读捕获 | 180 ns | 外部预算120 ns，保留60 ns（实际路径还须扣内部延迟） |

TimeQuest本次 RD/WR clock-to-pin 分别11.004/11.071ns，小于SDC预留24ns；读输入120ns预算=24+70×1.3+5，捕获只对read_data寄存器用setup9/hold8多周期，并非LCD接口整组false path。

## 3. 未约束路径与 false path 审计

未约束时钟0；setup和hold各有1个输入端口、58个输出端口，输入路径140、输出路径456。完整导出见 `p5a0_unconstrained.rpt`；本目录 `unconstrained_paths.csv` 为每条路径保留 analysis、source、target、clock 和中文原因，共1192条（setup/hold分别列出；输入/输出类别可重复涵盖同一物理路径，不解释为1192条独立电路）。脚本断言数量与报告一致。

| 对象 | 数量/说明 | 原因与处理 |
|---|---|---|
| sw7 | 140条输入路径/每种分析 | 原始SW7除同步器外还用于即时关断门控，扇出至输出及内部寄存器；这些路径未设输入到达或最大延迟，不能称全部同步化或已签核 |
| buzzer | 1个输出 | 无同步接收时钟/输出delay；载波半周期250us，不以节拍慢为理由隐藏板外约束缺失 |
| cat_n[0..7]、seg_a..g | 15个输出 | 视觉显示、250us扫描步长，缺外部负载与delay规格；约40ns消隐的板外效果仍需实物验证 |
| matrix_row_n[0..7]、matrix_col_r/g[0..7] | 24个输出 | 同上；色相周期8ms |
| led[0..15] | 16个输出 | 视觉输出、2Hz闪烁；无外部同步采样边沿，未定义负载时限 |
| servo | 1个输出 | 1us计数步长、20ms帧，未定义板外delay |
| trig | 1个输出 | 1us计数步长、约15us高脉冲，未定义板外delay |

本轮没有新增任何false path，也没有用虚构同步输入/输出delay凑成零未约束。用户允许“清零或逐条说明”，此处采用后者；正setup/hold仅覆盖已约束路径。

现有SDC恰有以下3条false path，均仅截止同步首级，第二级仍按50MHz分析：

| 起点 -> 终点 | 现有理由 | 对本次规则的判断 |
|---|---|---|
| sw7 -> sw_meta[0] | 异步机械开关首级 | **不在允许的LCD/UFM/超声/舵机范围内，未放行**；20ms采样是消抖节拍，不能作为异步相位建立保持余量 |
| sw6 -> sw_meta[1] | 异步机械开关首级 | **同上，未放行** |
| echo -> echo_meta | 超声异步ECHO首级 | 接口类别在允许范围内，但属于异步CDC例外，不是“计数使能下多周期”的证明；首级无确定setup/hold相位余量，后级20ns检查保留，不能拿1us节拍替代CDC论证 |

因此按本次“只允许按计数节拍控制的慢接口”严格口径，原SDC不能认定全部合规。审计不擅自保留并宣称合规，也不把真实异步输入伪装成与clk同相。可选后续路线：①保持RTL，改用针对首级的显式最大/最小传播延迟预算，核对Quartus9.1实际分析范围并重新整机编译；②用户明确允许同步首级CDC例外。未选择/解决前，不推进P5a-1。任何路线都保留逐条未约束说明，不对整组显示输出设置false path。

## 4. 最坏帧耗时与吞吐量

本轮重跑375个受控请求、17807像素、416条A/375条B、142456笔总线事务；逐次检查向量、锁存、dummy/real read顺序和整块1056字节显存，全部通过。测试每次等待ready，涵盖完整往返和附加目标/端区场景；不等于所有角度×距离组合已穷举。

按50MHz，每个像素6次写×16clk + 2次读×40clk =176clk；事务请求/完成握手和串行坐标/旋转及状态转移列入其余开销。UFM尚未实例化，读耗时为0。

| 场景 | UFM读取 | LCD读 | LCD写 | 状态机/运算/握手 | 总计 |
|---|---:|---:|---:|---:|---:|
| 普通实测最坏（170°、43像素） | 0 | 0.068800ms | 0.082560ms | 0.418680ms | **0.570040ms** |
| 端区实测最坏（180°下降、444像素） | 0 | 0.710400ms | 0.852480ms | 0.981900ms | **2.544780ms** |

连续1°步进60ms，实测最坏端区帧余量57.455220ms，占周期4.2413%。不采用后续UFM/XOR版本尚不存在的预计值代替本步结果。

额外给出比测试覆盖更保守的当前RTL处理上界：每请求至多190个定向度、每度至多3个微步，按200clk/度包络；至多12条射线×49个径向位置，按64clk/位置包络；至多444次RMW，按256clk/次包络（实际总线+握手约192clk）；另留4096clk控制余量。合计≤193392clk=3.867840ms，仍比60ms少56.132160ms。该包络有意重复计部分状态，仅针对初始化完成后、无外部复位打断的当前参数，不能用于P5a-2/3。上电清屏及毫秒等待不属于一次绘图请求，后续替换UFM初始化时须另测。

基本快走每16us，当前帧耗时明显超过请求间隔；本轮整机加速测试记录basic_fast_step_drops=180、continuous_drops=0。受控绘图的dropped=255来自刻意饱和注入，不能当真实丢弃率。原版没有忙时请求合并，这是P5a-1计划修复项，不将本轮通过写成该功能已存在。

整机仿真：17次触发、7个基本样本、8个连续样本、2次模式切换、3159次LCD读取，PASS。日志分别位于 `p5a0_draw/budget_f15/`、`p5a0_top/`；测试与RTL哈希均保留。没有观察到相对原版的功能回归，但仿真不能代替实物验收。
