# P5a-0 实物验收清单（待用户填写）

对象：当前已烧录的 1089 LE、ENABLE_READBACK=1 版本。本轮重新生成的 POF 与原烧录文件 SHA-256 一致；没有执行烧录，没有修改 RTL。

请在同一份烧录文件中用 SW6 分别测试基本模式和连续模式。每次切换会重走自检/待机并重新初始化 LCD；等待 RUN 后再观察。建议每种模式至少观察一个完整往返：基本约16秒，连续约21.6秒。记录近距离、远距离、目标移开和端点换向后的表现。

| 检查项 | 操作与合格现象 | 基本 SW6=0 | 连续 SW6=1 |
|---|---|---|---|
| 圈完整 | 扫描充分覆盖后，r16/32/48 三条半圆圈均连续，无固定缺口；特别看基本快走段和两侧端点 | 待确认 | 待确认 |
| 目标单点 | 固定方向放置稳定目标，单次有效目标为一个像素，不扩展为短竖线或块；换距离后记录是否有旧点残留 | 待确认 | 待确认 |
| 无竖条 | 扫描、目标变化、0°/180°换向后，没有8像素页高条纹、整列竖条或随角度扩散的条带 | 待确认 | 待确认 |
| 无错位 | 0°向右、90°向上、180°向左，圆心在底部中间；三圈同心，左右不镜像，页/列边界无跳位 | 待确认 | 待确认 |
| 切换后恢复 | SW6切换及SW7重启后，初始化完成能重新形成正常画面，不保留上一模式的乱码 | 待确认 | 待确认 |

补充确认：液晶 PCB 跳线保持 Intel 8080 模式（手册默认）；当前没有 DEG 文字、XOR 扫描线和报警反显，不将这些未来功能作为本版验收项。

单点指一次绘制的目标形状；原版会保存扫描历史，不要求整个屏幕同时只有一个目标点。当前 A 步提前10°、基本快走忙时丢弃请求，完整圈与残留是否可接受必须以实物观察填写，仿真受控请求通过不能代填。

请按以下格式反馈即可：

```text
基本：圈完整 / 目标单点 / 无竖条 / 无错位 / 切换恢复（各项通过或具体异常）
连续：圈完整 / 目标单点 / 无竖条 / 无错位 / 切换恢复（各项通过或具体异常）
8080跳线：确认 / 未检查
```

进入 P5a-1 前还须处理审计报告所列 SW6/SW7 false path 与本次规则的冲突。实物正常与约束规则合规是两个独立条件。用户确认前不进入 P5a-1；P5a完成后也不自动进入 P5b。
