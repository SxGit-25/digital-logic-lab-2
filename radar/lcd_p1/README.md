# P1：独立液晶接口测试（待 Quartus 实测及上板验收）

本阶段不接入 radar_top，不改动原有基本要求模块。用户已确认沿用 A0/C8、对比度 0x1C。仅准备 P1；收到两份编译报告并经用户确认后才进入 P2。

## Windows 编译

在仓库根目录执行：

```powershell
powershell -ExecutionPolicy Bypass -File radar/lcd_p1/compile.ps1
# Quartus 位于其他位置时：
powershell -ExecutionPolicy Bypass -File radar/lcd_p1/compile.ps1 -QuartusBin 'C:\altera\9.1\quartus\bin64'
```

脚本隔离到 ASCII 临时目录编译两个工程，保留日志、完整报告、引脚表、编程文件和源码 SHA256。请回传整个 `radar/lcd_p1/results` 目录，失败时也保留日志。脚本从未自动下载到硬件。当前 Mac 无 Quartus，脚本尚未经 Windows 实跑；不可把仿真结果当作 Fitter/TimeQuest 结果。

| 工程 | 数据引脚 | 用途 |
|---|---|---|
| lcd_p1_write | output，始终驱动；RD 恒高，无输入采样 | 初始化、清屏、三个半圆 |
| lcd_p1_read | inout，写时驱动，读及空闲高阻 | 初始化、清屏、写 FF、重设地址、空读、真读、LED 输出 |

通用 lcd_bus 和 lcd_p1_core 的 ENABLE_READBACK 默认仍为 0。只有名称明确的 read 顶层显式覆盖为 1，作为需电气确认的独立测试文件。MAX II 编译通常输出 `.pof`，以实际生成物为准。

## 实现与仿真

- `lcd_bus`：请求/完成握手，独立数据输入、输出、输出使能；物理三态仅在 read 顶层。
- `lcd_init`：复位低 1 ms，释放后等待 20 ms；A2/A0/C8/2F，电源等待 20 ms，再 24/81/1C/40，8×132 字节清零，最后 AF。
- `lcd_p1_core`：初始化后独占总线，完成后停止。只写图案来自离线浮点生成的固定参考图，不是 P2 的 sin 表/累加绘图器，其资源不得当作最终绘图引擎预算。
- `generate_pattern.py`：对 0..180°、半径 16/32/48 生成固定图；圆心 (64,63)，最高点 y=15，前两页中的 y=0..14 均空白。运行脚本可重新生成 ROM 和 expected.hex。
- `st7565_model`：8×132 RAM、页列地址、列递增、延迟读缓冲、地址后空读、70 ns 读访问、50 ns 释放，检查初始化顺序、清屏、总线所有权和时序。
- 仿真入口：`sh radar/lcd_p1/run_sim.sh`（需 Icarus）。输出 `p1_rings.pbm`；随附 PNG 是该显存导出图。图像已人工查看，三个半圆连续，底边中点为圆心，顶部保留空白。
- 只写路径所有可见字节与参考图对照，隐藏 4 列保持零；回读检查恰好两次读及 LED=FF；每个时钟检查只写模式 OE 恒高且 RD 恒高。
- 原有 5 套基本回归及额外 baseline 差分回归须通过，结果记录在资源报告。

P1 不包含 A/B 提前擦除、目标点、完整往返扫描、sin 两种实现或累加器误差测试。这些属于 P2，尚未实现或验证。P1 模型当前覆盖普通读写，未来若采用 E0/EE，需同步扩展模型。普通读会推进内部地址；未来像素写回必须重新设置原列地址，或正确使用 E0/EE，不能直接向读后的列写回。

## 时序与约束

主时钟 50 MHz（20 ns），以下参数在 lcd_bus 内可配置；改变参数或时钟后必须重验。

| 项目 | 手册要求 | 加 30% 后 | RTL 默认 |
|---|---:|---:|---:|
| 写低 | ≥80 ns | ≥104 ns | 120 ns（6 周期） |
| 读低 | ≥140 ns | ≥182 ns | 200 ns（10 周期） |
| 写数据建立 | ≥40 ns | ≥52 ns | 80 ns（4 周期） |
| 恢复高电平 | ≥80 ns | ≥104 ns | 120 ns（6 周期） |
| 总线周期 | ≥240 ns | ≥312 ns | 写事务 320 ns，握手另有间隔 |
| 读访问上限 | 70 ns | 按 91 ns 留预算 | RD 下降后 180 ns 采样，上升前 20 ns |
| 读前释放 | 用户要求 ≥1 总线周期 | — | 400 ns，再进入 80 ns 建立阶段 |

每次读都先释放 400 ns，包括连续的空读和真读。LCD 释放最坏 50 ns，读后至少有 120 ns 恢复时间。只写模式始终驱动最近一次命令/数据，符合用户确认的例外规则。

SDC 给输出 5 ns 外部走线/负载预算；回读输入预算 96 ns = 70×1.3+5，输入仅至 read_data 捕获寄存器应用 setup=9/hold=8 的多周期。依据是 RD 下降到采样相隔 9 拍。未对所有接口宽泛 false-path。此为初始工程约束，必须在实际 TimeQuest 确认集合匹配、输入捕获路径、输出最大/最小延迟和 hold；模型测的是 RTL 波形，不能代替引脚延迟签核。

输出约束通过后仍需比较 RD/WR/A0/数据的引脚延迟差：写低剩余 16 ns、读低 18 ns、建立 28 ns、恢复 16 ns 是保持“30% 余量”允许消耗的差值。若 Fitter 路径或示波器结果超出预算，延长对应参数并重新编译。不要仅凭内部 setup slack 宣称液晶接口通过。

## 上板核对清单（回读前必须完成）

- [ ] 拍摄模块背面，识别稳压芯片及实际控制器供电；模块标称 5 V 不等于 DB 输出为 3.3 V。
- [ ] 查实验板原理图：DB0..7 是否有缓冲、电平转换、串联电阻；记录器件型号、方向控制、阻值及供电。
- [ ] 依据 MAX II 手册核实输入钳位、允许电流及串联电阻条件。不可仅凭“5 V 容忍”字样判断直接连接安全。
- [ ] 在具备输入保护/隔离的测试接线下读取 FF，用示波器或万用表测 LCD 侧 DB0..7 高电平；记录电压与供电。示波器优先（读脉冲仅 200 ns，普通万用表无法可靠捕获单次脉冲）。需要专用测试夹具或受保护的重复读测试时另行准备，当前测试只读一次。
- [ ] 测量时不得让未知 5 V 回读直接进入 CPLD；隔离方案必须仍允许向 LCD 写入命令和 FF。不要简单断开数据线后期待 CPLD 还能正常写入。
- [ ] 将以上照片、原理图结论及测量值交回，用户确认安全后才能下载 read 工程。通用默认值保持 0，除非用户另行批准修改。

### 只写上板

确认 50 MHz 输入、共地、模块供电与引脚表后，下载 write 工程。预期复位/初始化后显示三个半圆；LED 输出 FF 表示写入流程结束（是否亮灯取决于板上 LED 极性）。检查图案左右端点 (16,63)/(112,63)、最高点 (64,15)，记录是否存在偏列或上下镜像；不要通过猜测修改 A0/C8 或列偏移。

### 回读上板（仅电气确认后）

下载 read 工程，逻辑 LED[7:0] 应为 FF，page 0/column 0 的 8 个像素被置位。预期数据总线先高阻，再空读，接着真读；示波器检查无争用、读前高阻 ≥400 ns、RD 低 200 ns。FF 测试不能排除所有数据线粘连故障，必要时扩展 00/A5/5A 测试；本阶段只实现指定单字节测试。

若用户反馈回读不安全，停止极坐标实现，告知后进入无需回读的柱状图方案。

## 手册核对依据

模块手册 `LCM12864_14图形点阵液晶数据手册.pdf` 的 8080 时序表用于上述周期与脉宽。控制器 [ST7565R 数据手册](https://www.orientdisplay.com/pdf/ST7565R.pdf) 第 24–27 页说明空读缓冲及页内 D0→D7 对应递增的行地址；采用 `page=y[5:3]`、`bit=y[2:0]`。C8 的 COM 反向与模块玻璃接线共同决定实物上下方向，仍按用户确认的 A0/C8 上板核对。该控制器手册标注芯片逻辑供电 2.4–3.3 V，模块手册却标称 5 V，因此电气确认必须检查实际模块电路。
