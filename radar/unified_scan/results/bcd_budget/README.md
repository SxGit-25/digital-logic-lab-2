# 整数分频 BCD 测距预算实验

`ultrasonic_bcd_budget.v`，50 MHz，默认 `USE_MS_TIMEOUT=1`。接口在原实验版基础上新增全局 `tick_ms`；未使用局部分频产生微秒或毫秒节拍。毫米节拍 `/294` 在同步 echo 上升沿清零，不作半拍预置。

最终独立 Quartus 9.1 EPM1270T144C5 实测：144 LE、73 registers、37 I/O、UFM 0，Fitter 成功，50 MHz setup 2.112 ns / hold 1.078 ns。**未达到 120 LE 目标**；此为独立工程，不能与其余模块简单相加替代整机编译。

BCD 用同一个 4 位加法器在四个时钟内旋转更新；旋转计数复用 `/294` 相位，不加新计数器。只有工作和提交两份 BCD。提交值由 `distance_valid` 限定，复位时数据寄存器不作无意义清零。半径直接用工作/输出同一寄存器：测量时 `radius_valid=0`，结束后数值保持直到下次 start。超时与 trigger 复用计数资源：毫秒超时计31个全局tick，从任意相位保证至少30 ms、最多31 ms（另有同步和提交几个时钟）。

`distance_level` 是提交 BCD 的组合输出；若整机扫描模块重复计算阈值，可以不接本端口以便综合裁剪。阈值按 `<200 / >=200 / >=400 / >=600 / >=800` 分档；有效范围按**显示测量值**20..4000 mm（包括端点），不要求与旧毫米算法逐例一致。

`simulation.log`：20组数值边界，包含19/20、199/200、399/400、599/600、799/800、1199/1200/1201、3999/4000/4001，检查BCD位进位尚未结束时回波下降的三个偏移；还覆盖无回波、起始高回波、持续高回波超时、取消及取消后重新启动。全部 PASS。

`ideal_error.json`：穷举1,177,059个时钟宽度，测量公式 `floor((echo_clocks-1)/294)`，理想公式 `echo_clocks*0.0034 mm`。所有有效显示值的最大绝对误差 **1.5966 mm**，有符号范围 **[-0.9916,+1.5966] mm**，满足 ≤2 mm。这是对理想换算的直接比较，不是与旧 RTL 的差值。

复现：`radar/sim/unified_scan/run_bcd_budget.ps1 -Quartus` 及 `analyze_bcd_budget.py`。RTL/测试/约束随本目录报告保存。独立工程未烧录，整机回归由后续集成负责。
