## 统一引擎与验收差异

`radar_unified_scan`仅有一组BCD角度、方向、PWM、测距调度与5线历史。SW6只选节奏，显示始终使用同一角度BCD，seg/matrix/alarm复用；旧radar_ctrl/servo_pwm未接入新顶层。连续默认60ms走1°，待目标PWM已应用后每步测距一次。基本每2s槽快走45×16us=720us，首槽保留0°，槽起300ms测量；快走期间PWM保持旧完整目标。

默认生产时序实测证明slot与PWM rollover同拍，快走发生在该帧锁存后。新旧最终目标同在slot+20ms的帧应用，额外延迟0clk；快走结束到应用仍有19.28ms。后续采样按新规则slot+300ms，而旧版slot+320ms，所以**提前20ms**；首0°样本同拍。显示中间BCD≤720us，seg脚位差保守≤970.02us；人工错相位HOLD保障最多延迟1帧且不出现中间脉宽。全部具体时间和预期调整逐条列在契约，未修改旧六套测试。

新独立验收包括basic全往返、continuous全181角×双向、5线归类、无效样本、历史、模式重启/关闭、人工错相位及生产参数。原六套基础回归仍通过，但只代表保留旧模块；不将此说成新顶层与旧版逐周期完全相同。

额外时序检查发现尚未解决的范围冲突：原点阵复用RTL在历史输入提前20ms时，可使可见变化相差23.25ms，超过用户20ms边界，见`results/matrix_latency/`。已先报告并等待选择恢复旧采样时刻或明确接受点阵刷新余量；当前实现仍槽+300ms，未擅改测试放行。

## Minsky实现与失败项

单次整数shift的旋转步长不能同时保证1°对齐和≤1px；最终主候选F15/k7、每逻辑角执行2或3微步（+15 mod64，初相位63），只用共享1bit全加器串行执行向量与坐标。外部角度仍1°，第45步实际方向44.981508°，全角度/全半径最大欧氏像素误差0.913512px；MIN6后方命中0；正逆逐角向量和phase完全恢复。

删除sin/UFM/象限翻转/bridge/队列。每个accepted请求重建canonical首射线，再正逆执行A/B和端区11条A，避免丢请求导致方向状态失步。v2复用方向/半径计数器、位串行/RMW事务计数器；数据寄存器通过显式微指令初始化，保留drop饱和计数。控制计数与BCD输入转换仍消耗面积，**绘图本体328 LE，超过200目标128 LE**；在整机上下文为317 LE，不能混用这个上下文差值当独立节省。

375个accepted请求、17807个逐像素RMW、416A+375B、142456总线事务、每次完整1056字节RAM、所有向量、最小半径夹6、invalid、busy入参扰动、drop255及丢弃后的正确恢复均通过。完整0→180→0及多目标换向导出两张PBM/PNG，已查看：圆心在(64,63)，圈半径16/32/48，页0空白，目标与独立期望显存一致。

**时限仍失败**：普通compact F15请求最坏0.569860ms，端区最坏2.544740ms，375请求中6次端区超过严格1ms，仿真保留退出1。每条A有40个RMW，端区440个RMW；现bus八事务仅脉宽/turnaround已176clk/RMW，所以不计B/握手/计算就1.5488ms。保留端区与当前逐像素访问时，不能只靠加快Minsky达到1ms；需要字节合并或另一种保留像素集合的访问重构。未偷偷去批量或缩短脉宽。

## 顶层请求与实际丢弃

两种模式共用请求规则：已有测距待办时不另画无目标的step请求，结果提交再画一次完整A/B，避免短回波目标被同角度冗余绘图挡掉。不是SW6关闭逻辑，没有队列。忙时仍丢弃新请求并保留计数。

最终双顶层readback0/1集成7261546周期、89次触发、47次基本/41次连续结果提交、两次测量中SW6切换、SW7亚周期关闭通过；原58位输出不受LCD启用影响。真实ST7565模型完成2176次读，两模式均实际绘图，默认RD恒高且无读。该**加速联调场景**基本接收5个结果绘图、连续6个；观察窗基本快走丢176个中间step请求，连续丢0。不要将该计数外推为生产丢失率。

16us快走与完整绘图速度不匹配，故不能保证基本模式每条中间射线都绘制，也未证明有丢请求时所有旧目标擦除都满足完整显示规格；这是除面积/端区时限外的未完成项。受控375请求显存验证没有替代真实快走完整性验收。

行为模型修复了一项测试缺陷：原模型把历次复位累计清屏次数用作“本次开显示前必须1056字节”的判断；新增每次复位清屏/初始化计数，同时保留全局读写计数，才可正确验证多次SW6重初始化。初始失败日志保留，未改变任何LCD RTL时序或旧六套预期。
