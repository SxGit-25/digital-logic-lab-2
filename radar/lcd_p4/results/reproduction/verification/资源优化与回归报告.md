## 实际改动

各模块使用 Verilog-2001 编译期常量函数 `count_width`，按参数计算 ceil(log2(计数周期))，最小为 1 位。没有新增运行时计算电路。参数应为正整数，时钟仍须满足原有整 MHz 限制。

| 模块 | 计数器默认宽度变化 | 模块逻辑单元变化 |
|---|---|---:|
| timebase | 32/32/32 → 6/10/8 | 136 → 39 |
| switch_filter | 32 → 5 | 48 → 12 |
| radar_ctrl | 状态/时隙/稳定等待 32/32/32 → 11/11/9 | 271 → 184 |
| seg_scan | 32 → 8 | 107 → 75 |
| matrix_scan | 32 → 8 | 114 → 81 |
| alarm_ctrl | 载波/节奏 32/32 → 8/10，周期选择值收窄至 10 位 | 115 → 56 |
| ultrasonic | 触发/超时/回波 16/16/16 → 4/15/15 | 154 → 133 |

舵机 PWM、显示内容、BCD 转换、上电复位、顶层引脚及主状态机接口保持原样。循环展开变量和编译期参数保留 integer，不把它们误当成运行时寄存器。

报警修复：原代码使用 `rhythm_ms == rhythm_period_ms - 1`，若计数已达 800 ms 时周期从 1000 ms 改为 125 ms，会错过新的回绕点。改为 `>=`，在下一个毫秒使能回绕，再恢复正常 50 ms 鸣叫包络。固定档位的四种周期不变。这是本次有意的行为修复，不属于严格等价变换。
