# 基础版资源优化与回归记录

日期：2026-09-20。范围：收窄计数器位宽、修复报警周期缩短时的回绕问题、基础功能仿真及完整编译。未加入液晶或连续扫描功能，未下载到实物板。

## 编译对比

原版与优化版均在本机 Quartus II 64-Bit 9.1 Build 222 重新完整编译，目标器件 EPM1270T144C5，主时钟 50 MHz，沿用相同 QSF/SDC。

| 指标 | 原版 | 优化版 |
|---|---:|---:|
| 逻辑单元 | 1208 / 1270（95%） | 843 / 1270（66%） |
| 可用逻辑单元 | 62 | 427 |
| 寄存器 | 657 | 385 |
| I/O 引脚 | 61 | 61 |
| Fmax（内部同钟路径） | 57.44 MHz | 66.42 MHz |
| Setup slack | 2.591 ns | 4.944 ns |
| Hold slack | 1.078 ns | 1.078 ns |
| 完整编译 | 0 errors, 0 warnings | 0 errors, 0 warnings |

逻辑单元减少 365 个，较原版减少约 30.2%；寄存器减少 272 个。427 个剩余逻辑单元是后续扩展空间，不代表液晶功能必然能容纳，仍需增量综合验证。

## 实际改动

各模块使用 Verilog-2001 编译期常量函数 `count_width`，按参数计算 ceil(log2(计数周期))，最小为 1 位。没有新增运行时计算电路。参数应为正整数，时钟仍须满足原有整 MHz 限制。

| 模块 | 计数器默认宽度变化 | 模块逻辑单元变化 |
|---|---|---:|
| timebase | 32/32/32 → 6/10/8 | 136 → 39 |
| switch_filter | 32 → 5 | 48 → 12 |
| radar_ctrl | 状态/时隙/稳定等待 32/32/32 → 11/11/9 | 271 → 184 |
| seg_scan | 32 → 8 | 107 → 75 |
| matrix_scan | 32 → 8 | 114 → 81 |
| alarm_ctrl | 载波/节奏 32/32 → 8/10，周期选择值收窄至 10 位 | 115 → 56 |
| ultrasonic | 触发/超时/回波 16/16/16 → 4/15/15 | 154 → 133 |

舵机 PWM、显示内容、BCD 转换、上电复位、顶层引脚及主状态机接口保持原样。循环展开变量和编译期参数保留 integer，不把它们误当成运行时寄存器。

报警修复：原代码使用 `rhythm_ms == rhythm_period_ms - 1`，若计数已达 800 ms 时周期从 1000 ms 改为 125 ms，会错过新的回绕点。改为 `>=`，在下一个毫秒使能回绕，再恢复正常 50 ms 鸣叫包络。固定档位的四种周期不变。这是本次有意的行为修复，不属于严格等价变换。

## 验证边界

TimeQuest 仍提示外部 I/O 未完整约束：1 个输入端口、58 个输出端口。原有 SDC 只约束主时钟及两个同步器入口；本次未通过添加宽泛 false path 隐藏未约束路径。因此本报告的时序通过结论限于已约束的内部路径，不表示外部接口时序已经全部签核。

尚需实物确认：50 MHz 时钟设置、2 秒自检和待机、五方向往返、各距离报警档位、点阵颜色及朝向、SW7 关机重启。仿真和编译不能替代机械运动及传感器实测。
