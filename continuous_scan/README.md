# 独立连续扫描实验

本工程只验证 SG90 舵机连续往返扫描，基础版 `../radar/` 的 RTL 和工程未修改。目标器件 EPM1270T144C5，默认板上时钟 50 MHz。

## 使用

下载 `output/continuous_scan.pof`。沿用原接线：时钟 PIN_18，SW7 PIN_125，舵机信号 PIN_51，舵机电源 5V，共地。

1. SW7 关闭：关闭 PWM 和所有显示。
2. SW7 开启并稳定约 20 ms：从 500 μs 脉宽开始，保持 50 帧（1 秒），使舵机有时间返回 0°。
3. 随后每帧增加 5 μs，达到 2500 μs 后每帧减小 5 μs；到 500 μs 再反向，持续往返。
4. 运行时 LED0 常亮，LED1 表示脉宽递增，LED2 表示脉宽递减。数码管、点阵、蜂鸣器及超声波触发保持关闭。方向指示表示下一步的指令方向。
5. SW7 关闭立即门控 PWM，主时钟随后复位扫描状态；再次开启重新执行回零保持。

去掉控制脉冲不等于机械制动；角度标称值沿用题目，实际转向和端点由安装及舵机决定。

## 参数及行为

| 参数 | 默认值 | 含义 |
|---|---:|---|
| FRAME_US | 20000 | 50 Hz PWM |
| MIN_PULSE_US | 500 | 标称 0° |
| MAX_PULSE_US | 2500 | 标称 180° |
| STEP_US | 5 | 每帧变化约 0.45°，指令速度约 22.5°/s |
| STARTUP_FRAMES | 50 | 初始零度脉宽保持 1 秒 |

稳定往返单程为 400 帧即 8 秒，往返 16 秒。首次启动先输出 50 个完整的 500 μs 脉冲，随后开始步进，因此首次到达最大脉宽约在启用后 8.98 秒。后续端点各只占一个正常帧，没有额外停顿。

`continuous_scan_top.v` 暴露 `CLK_HZ`、`SWITCH_MS`、`STEP_US`、`STARTUP_FRAMES`。例如将 STEP_US 从 5 改为 10，单程变为约 4 秒。更改后必须重新编译；改变 CLK_HZ 时还必须同步修改 SDC 的时钟周期。

端点脉宽和帧周期定义在 `servo_sweep.v`，可通过实例参数校准。约束：1 <= MIN < MAX <= 4095，FRAME > MAX，1 <= STEP <= MAX-MIN，STARTUP_FRAMES >= 0。步长不能整除范围时，最后一步饱和到端点，不越界；STARTUP_FRAMES 为 0 或 1 时保留必需的首帧 MIN，第二帧开始步进。

PWM 仅在 `tick_us` 对齐的帧起点启用，每帧边界更新脉宽，避免中途更改造成脉冲拼接。所有寄存器仍使用同一主时钟，tick_us 只是时钟使能。

`active_pulse_us` 是当前已经应用的指令，`frame_start` 为单主时钟周期脉冲，供以后测距角度绑定使用。它们不是实际机械位置反馈。匀速改变指令只能近似机械匀速，仍需上板确认。

## 编译和仿真

在本目录执行：

```powershell
.\compile.ps1
.\sim\run_tests.ps1
```

编译脚本默认使用 `E:\quartus\QuartusII91\quartus\bin64`，临时英文盘符避免旧版 Quartus 的路径解析问题，报告及 POF 保存到 `output/`。仿真优先使用本机 `../radar/sim/tools/iverilog/app/bin` 中的便携 Icarus；从 GitHub 克隆后可通过 `-IverilogBin` 指定 Icarus 的 `bin` 目录。时基、开关消抖及上电复位也直接引用基础工程，不复制另一个维护版本。

本机 Quartus II 9.1 完整编译结果：152/1270 个逻辑单元（12%），Fmax 66.28 MHz，50 MHz setup slack 4.913 ns，hold slack 1.380 ns。零错误；55 条警告均为主动关闭的输出引脚固定在 VCC/GND（含一条汇总），未屏蔽这些提示。

时序报告仍有未约束外部 I/O，内部时序通过不表示外部接口全部签核。未执行实物下载和机械运动验证。

## 上板验收

- 开关开启后先回零，约 1 秒后平缓扫描；稳定后单程约 8 秒、往返约 16 秒。
- 0°和180°附近没有额外长停顿、抖动或明显顶死；必要时按实物校准脉宽端点。
- SW7 关闭后 PWM 停止，再开启重新回零。
- 如有示波器，确认周期 20 ms，脉宽从 0.5 ms 以每帧 5 μs 递增到 2.5 ms，再递减；方向变化时不拼接脉冲。
